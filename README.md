# 弦の鳴りかた / String Lab

バイオリンの弓・弦の条件を動かし、規則的な振動が成立しうる範囲を図で比べる、日本語のWebアプリです。

公開アプリ: https://ngmt4amtk-web.github.io/violin-string-lab/

## 操作できる条件

- G・D・A・E弦、開放弦から24半音上までの音高。同じ音高を別の弦で比べる設定
- 駒からの距離、弓速、弦に垂直な弓の力
- 押さえる音を変えても駒からの距離は固定。高い音では自分で駒へ寄せて試す
- 弦の張力（4銘柄のミディアムの目安ボタン、折りたたみ）

範囲の帯、弦の動き、距離と力の地図を表示します。A/B比較、現在の条件を含む共有リンク、PNG保存に対応。スマホでは上に固定したステージで帯・弦の動き・地図を切り替え、iPadでは右の条件パネル内をスクロールします。鳴りの大きさは初期のA線を100%とした理想模型の目安です。各条件のⓘで説明を開けます。ダウン／アップは図の向きだけを切り替えます。音は鳴りません。

## 模型の範囲

Schellengの古典的な定常音の成立条件を用いた教材です。境目の数値は特定の楽器・製品の測定値ではありません。張力の製品ボタンは出典付きの参考値です。初期値はA4・55 N・32 mm・10 cm/秒・35 gf。G/D/A/Eの初期張力は仮定であり、素材や弦の銘柄の優劣を予測しません。

緑の帯は必要条件による近似で、規則的な音の保証ではありません。押弦による損失倍率は教材上の追加仮定です。弾き始め、弓返し、実際の音量・音色、ねじれや曲げ剛性、弓毛の幅・傾き、松脂の温度依存性、共鳴やウルフ音はモデル化していません。

弦のアニメーションは成立範囲では理想的な進行する角の形、範囲外では静止した模式図です。時間の表示は、共通のスロー倍率と1周期ずつの観察を切り替えられます。実測波形や数値シミュレーションの再現ではありません。

出典と計算式はアプリ内の「しくみ・出典」にあります。

## 開発と検証

本番依存なし、ビルド不要のHTML/CSS/JavaScriptです。`dist/` が公開ファイルです。

```sh
python3 -m http.server 8874 --bind 127.0.0.1 --directory dist
node --test tests/model.test.mjs
```

ブラウザ検証は既存のPlaywrightとブラウザで実行できます。`PLAYWRIGHT_PATH` にPlaywrightのモジュールパス、`CHROMIUM_PATH` と `WEBKIT_PATH` にそれぞれの実行ファイルを指定できます。未指定の場合は通常のPlaywrightの配置を使います。

```sh
node tests/browser.cjs
```

`TEST_URL` で検証先を、`QA_DIR` で検品ファイルの出力先を変更できます。ブラウザでの検証と、iPhone実機・実際のバイオリンでの検証は別です。

`main` にソースを、`gh-pages` に `dist/` の内容だけを配置し、GitHub Pagesで配信します。個人の原教材、相談ログ、検品画像は公開リポジトリに含めません。

## データ

Aに保存した条件だけをブラウザのlocalStorageに保存します。リンク共有には現在の条件のみが含まれます。アクセス解析、外部フォント、外部APIは使いません。
